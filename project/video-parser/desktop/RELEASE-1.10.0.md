# 跑量影链工坊 1.10.0

Windows x64 正式版，按当前已实现功能范围发布，不代表旧版 36 项规划全部完成。

## 本次更新

- 窗口按屏幕可用区域打开并保留任务栏空间；布局随窗口变化，全界面统一 14/16/20 三档字号。
- 压缩链接输入区和封面，主内容区统一滚动；侧栏飞书自动下载保持可达。
- 直播失败详情可展开查看，不再用整段错误撑大卡片。
- 飞书支持 `分类 测试`、`分类：测试`、`分类: 测试`，可放在分享文案末尾。
- 同一链接补写新分类时更新归档，不重复下载；仅修改备注不重置已有分类。
- 包含 TikTok FLV 直播兼容补丁，接口异常不再一律误报主播未开播。

## 飞书分类用法

直接把以下内容发给已配对的个人助手：

```text
视频链接或整段分享文案
分类 护肤/口播
备注 开头很好
```

也可以全部写在同一条消息末尾。补分类请回复原来的链接消息，或把同一链接带新分类再发一次。
回复会显示实际分类。只写备注时，新任务沿用“备注作为文件夹”的规则；未写分类/备注放入待分类。
文件会在该条视频完成当前处理后归档；电脑关机/软件退出期间不会下载。

## 保留配置升级

- 1.1.8-beta 用户：退出程序后覆盖安装到原试用版目录，不要先卸载或删除应用数据。沿用原内部标识和程序文件名以保留飞书、登录会话、代理、模型位置及任务记录；界面显示正式版。
- 新用户正常安装即可，模型仍按需下载，不随包捆绑。
- 独立旧版 1.1.8 稳定版与本次工作台原本是两套数据。此次不自动覆盖那套旧数据，也不强制把旧通道更新到新工作台。需要手动安装和确认对应配置。
- 新工作台的签名更新使用独立 `paoliang-latest.json`；旧版 `latest.json` 保持旧通道，避免错读另一套配置。
- 更新包包含 Tauri 更新签名；Windows 安装程序无 Authenticode 发布者证书，可能提示未知发布者。

## 支持边界

- 这是本次 UI、分类、下载回归及同标识升级的正式发布，不声称所有平台所有链接都可下载。
- TikTok 挂商品短视频尚有上游只返回音频的案例，本轮应用实测样本的官方嵌入页还返回了 HTTP 503；直播修复不能据此视为短视频全部修复。
- 真实双员工双电脑、全部平台、全部模型/API 组合和长时直播未在本轮全部重新验证。
- 断点续传、直播断线自动续录、评论/图文、关注/收藏、云端语音识别不在本次承诺范围；订阅仅扫描设定范围内的公开作品。
- 网络、平台登录/风控、地区及代理状况会影响解析。平台会话只在本机保留，不上传到公司收件服务。

具体测试证据见仓库 `qa/release-1.10.0.md`。
