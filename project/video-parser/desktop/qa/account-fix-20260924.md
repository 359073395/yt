# 账号状态与下载失败修复验收（2026-09-24）

## 现场证据

Windows 实际安装版 `D:\跑量影链工坊试用版\paoliang-preview.exe`，版本 1.1.8-beta.1。两条飞书收件任务均显示：`ERROR: Could not copy Chrome cookie database`。当时应用专用 Edge 登录进程仍在运行，Cookie 数据库被占用。用户随后明确确认已经关闭官方登录窗口。

原账号页只展示固定说明，没有按平台读取状态；原下载命令只要发现 Cookie 文件存在，就为所有平台添加 `--cookies-from-browser`，会把匿名 Cookie 文件误认为已登录，并因数据库占用阻断所有下载。

## 修复

- 各平台显示检测到会话、未检测到登录、等待同步、已保存但待同步；自动刷新与手动刷新均不阻塞界面。
- 使用 yt-dlp 对本应用专用 Edge 资料目录进行无网络的会话导出，按平台域名和未过期登录标志筛选，Windows DPAPI 加密保存。
- 下载进程只读取目标平台的独立临时 Cookie 快照，不再直接读占用中的浏览器数据库；完成/失败后清理临时快照。
- 数据库占用时保留上次安全快照；没有可用会话时仅尝试公开访问，不谎报登录成功。会话存在不等于服务器已确认有效。
- Cookie 占用、解密失败有明确中文提示；普通解析有进程超时上限。
- 不关闭用户浏览器、不修改系统安全设置、不安装插件、不要求用户手工导出 Cookie。

## 真实原生流程验证

使用显式启用的 `account-smoke` 验收程序调用与安装版相同的 `account_statuses`、`inspect_item` 和 `execute_download`。只读取试用版自己的登录资料和写派生会话缓存，不启动飞书收件线程，不修改原任务，也不发送飞书消息。
