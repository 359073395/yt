# 直播与订阅专项验收 — 2026-09-24

这是开发分支专项结果，不代表 36 项升级全部完成，也不等于正式安装包已发布。

## 实现范围

- 顶部直播、订阅从禁用占位改成独立可交互页面；窄窗口不隐藏入口。
- 订阅保存名称、分类、检查间隔、扫描范围、是否补下已有作品、是否自动下载。默认只建立历史基线，不擅自下载已有作品。
- Rust 后台定时扫描；同一订阅串行、持久去重、错误退避。自动收录与去重记录同事务保存。手动队列成功持久化后才确认原生待收记录，重放不会重复添加。
- 订阅沿用当前视频任务的输出/画质/模型/根目录设置；自动下载要求配置就绪，失败任务不会无限重试。暂停订阅不取消已经进入下载队列的作品。
- 抖音公开直播 API/SSR 解析；其他平台尝试现有 yt-dlp 直播提取器。普通视频不当作直播。
- 现有 FFmpeg 原流复制，10 分钟 MKV 分段，最多两路，同时设时长/容量/磁盘剩余空间保护；停止时先正常收尾，5 秒不退出则终止并标记部分保存。
- 退出托盘菜单会等待活动录制停止；断电/崩溃后显示中断记录，不伪装完成。未实现崩溃时 Windows Job Object 强制清理保证。
- 没有新增前端依赖、Python 服务、Electron 或付费中转。
