# 1.12.0 主页开播监控验收

2026-11-06，用户要求“给个主页链接，一旦博主开播了就开始录制”。本次在已发布的 1.11.0 上增加该功能；不将 1.11.0 的旧实测冒充为本版本实测。

当前：1.12.0 已于北京时间 2026-11-06 21:48:09 正式发布。功能实现、本地回归、TikTok / 抖音真实自动录制及重启回读均已完成。最终源码为 `6b7372aac93ecdbca0172c43dbcd90a5ed98ea99`；原生代码与已完成实测的 `ec2afc3` 相同。明细见 `qa/live-monitor-1.12.0.json`。本机原安装和个人数据未覆盖。

## 行为

- 支持 TikTok @用户名主页、抖音 /user/ 主页和数字直播间完整链接。首次检查发现已经开播，也会开始录制。
- 1～15 分钟检查，默认 1 分钟；最多 20 个监控，最多 2 路录制。2 个检查线程按到期顺序处理，平台慢响应不会阻塞全部监控。
- 明确的未开播状态、未知接口状态和网络失败分别处理。错误指数退避，最长 30 分钟；不把 HTTP 错误视为未开播。
- 场次去重和录制额度写入双快照；网络录制失败每场最多连接 3 次，并累计已耗时长和字节。达到上限、手动停止或完成后，等待下一场。
- 暂停和移除使检查中的旧结果失效，并停止关联录制；已有文件和录制记录保留。程序退出后下次启动会恢复已启用的监控。
- 关闭窗口时已启用的监控可留在托盘；退出程序、电脑休眠或断网期间不能检查。没有新增开机启动服务。
- 监控 Cookie 仅从工坊自己的加密会话读取到内存，并按官方域名、路径和 HTTPS 范围发送；监控 HTTP 请求不跟随重定向。媒体签名地址只留在内存。
