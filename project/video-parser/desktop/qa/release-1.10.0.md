# 1.10.0 验收记录

日期：2026-09-24。用户明确批准按当前已实现功能范围正式发布，不再等待旧规划全部完成。

## 1. 界面与交互

依据用户本轮提供的任务页和直播页截图：字号层级过多，输入区/封面太高，任务区嵌套滚动，侧栏底部难以看到。
保留现有导航与橙色主色，调整布局，不引入新 UI 库或额外运行时。

1. 视频任务：主内容区统一滚动；封面与输入区缩小。根据用户追加要求，全界面只保留正文 16、辅助 14、标题/品牌 20 三档字号，任务页和模型窗口均检查了浏览器计算样式。1280×800 下任务卡片按钮与飞书自动下载均完整可见，低矮窗口通过主内容滚动到达。
2. 小窗口：1280×720、1000×640、800×560 均无文档横向溢出；导航底部不超过页头，主内容底部等于视口，侧栏底部距视口 16 px。导航需要时分两行，不与内容重叠。
3. 直播：模拟创建、停止、下滑到记录卡片；1000×640 卡片底部 624 px，打开文件夹按钮完整可见。UI 模拟不作为真实录像证据。
4. 模型：1000×640 下滚动到底部，“保存翻译方式”按钮底部约 591 px，未裁切。模型位置、上游模型入口仍保留。

截图/尺寸原始证据位于本机 `F:\820\yinglian-personal-qa\release-1.10.0\ui`。
以上是布局、滚动和基本交互验收，不声称完整 WCAG 或全部辅助技术合规。

## 2. 飞书分类

旧代码仅接受带冒号的分类标签，并对重复视频只去重、不更新分类。
用户的实际消息末尾为 `... :4pm 分类 测试`。本轮加入完整分享文案、NBSP、Markdown 链接、中文标题的回归用例，确认入库只有一条且分类为“测试”。

覆盖有/无冒号、等号、制表符、嵌套文件夹、分类后备注、重复链接更新分类、重复裸链接不重置分类、仅补备注保留分类、越界/Windows 设备名称拒绝。平台原有 hashtag 不会随意变成文件夹。
既有真实双员工双电脑验收没有在本轮完成；单元测试的身份隔离不冒充该实测。
