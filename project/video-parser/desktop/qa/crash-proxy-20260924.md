# 飞书闪退与直播代理修复验收（2026-09-24）

目标版本：跑量影链工坊试用版 1.1.8-beta.3。保留原试用版应用标识和安装位置，不迁移或重建飞书机器人。

## 复现与修复

- 飞书收到 `https://v.douyin.com/B6-Fzz29S_Y/` 后启动下载，旧版 `parse_percent` 对含 NBSP 的标题使用错误的 UTF-8 字节边界切片，触发 panic；release 的 `panic=abort` 导致主进程退出。已改为字符边界安全的解析，并覆盖所有有效非 ASCII Unicode 标量回归测试。
- TikTok 直播解析成功但 FFmpeg 直连 TLS 握手被重置（10054）；旧版丢弃 stderr 并错误笼统声称已有分段。现提供软件内本机 HTTP 代理、冻结单次录制的代理配置，并显示脱敏后的实际错误和字节数。
- TikTok 当前 HLS 源还存在缺少时间戳导致 MKV 写入失败的问题；优先使用平台提供的带音视频 FLV 直播源，保留其他格式回退，不增加转码负担。
- 本机加密目录拒绝同目录原子重命名（Windows error 17）；代理保存改为两份交替刷盘快照，保留上一份完整配置，测试不完整写入恢复。

## 网络范围

入口：账号 → 网络代理 · v2rayN。支持跟随系统、手动本机 HTTP/混合端口、关闭代理。

本机实测端口 `http://127.0.0.1:10808`。默认仅海外平台走代理，抖音/哔哩哔哩直连；不会修改 Windows 或 v2rayN 设置，也不会改动飞书、AI 接口的网络配置。支持 yt-dlp、平台 HTTP 请求、官方浏览器窗口与 FFmpeg 录制链路。已有官方登录窗口需关闭后重开，新任务使用新配置。

不支持 PAC、SOCKS 专用端口、远程代理或代理用户名密码。使用 v2rayN 的 HTTP/混合端口，不要填写订阅地址。
