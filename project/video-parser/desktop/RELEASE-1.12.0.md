# 跑量影链工坊 1.12.0

新增主页开播监控。在「直播录制 → 开播自动录制」粘贴 TikTok 或抖音博主主页，选择分类、保存位置和每场录制上限，然后添加监控。当前已经开播也会自动开始录制。

- 默认每分钟检查，支持 3 / 5 / 15 分钟；最多保存 20 个监控，同时录制 2 路。
- 自动保存 MKV 分段，结束后继续等待下一场。支持立即检查、暂停、恢复、移除；已有视频和录制记录保留。
- 网络或平台错误会延后重试，不误报未开播。录制连接每场最多尝试 3 次，重连累计时长和容量。
- 手动停止或达到本场上限后等待下一场。监控、分类和保存路径会保留，重新打开工坊后恢复检查。
- 移除监控和博主订阅前显示明确的确认按钮，取消后继续保留；修复 Windows 录制中文件大小显示滞后而误报无数据的问题。
- 关闭窗口可留在托盘继续运行；退出工坊、电脑休眠或网络不可用期间不能检测开播。轮询不是零延迟，平台检查和排队可能增加延迟。

支持 TikTok `/@用户名` 主页、抖音 `/user/…` 主页和抖音数字直播间完整链接。短分享链接请先在官方页面打开并复制完整地址。抖音主页通常需要在工坊账号页登录。只访问官方公开直播数据；平台的登录、地区与访问限制仍然适用。

此版本在已验收的 1.11.0 基础上增加监控功能，不更换下载引擎、离线模型或七个平台的视频下载适配。独立旧版更新通道保持分离。

详细测试记录见仓库 `qa/release-1.12.0.md`。
