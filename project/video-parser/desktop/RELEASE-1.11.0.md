# 跑量影链工坊 1.11.0

## 更新内容

- yt-dlp 更新到 2026.10.26，FFmpeg 更新到 2026-11-05 的 LGPL shared 构建。新增随包 Deno 2.9.8，为 YouTube 的 JavaScript 挑战提供运行环境。
- 更新 Tauri、React、Transformers.js、Vite、TypeScript、Vitest、Reqwest、Tungstenite 等实际使用的依赖；重新锁定全部传递依赖，修复 Windows 依赖路径上的 TLS/证书相关已知漏洞。
- 适配新版 Reqwest 的表单特性，显式初始化 TLS 加密后端，避免 Reqwest 与飞书 WebSocket 依赖同时启用不同后端时崩溃。
- 修正更新组件的隐式代理探测，让“关闭代理（直连）”与系统/手动模式保持一致，不修改操作系统代理配置。
- 修正 TikTok 直播在辅助网页访问失败时的解析崩溃：已确认房间号后继续查询官方直播接口；保留真实网络错误和未开播状态。
- 修正抖音已登录仍无法解析的问题：适配当前网页接口的请求签名和视频来源头，校验返回的作品编号；不再把接口拒绝一概当作登录失效。兼容插件参考 yt-dlp 尚未合入的 [修复提案 #17826](https://github.com/yt-dlp/yt-dlp/pull/17826)，已用本机真实下载验证。
- whisper.cpp 1.9.5/b5454 与现有 M2M100 模型已经是本次核对的上游版本，继续复用。现有模型文件无需重新下载。
- 添加 npm/Cargo 每周依赖检查和官方运行组件更新检查；发现更新先报告、测试，不直接替换用户已安装组件。

## 验证范围与使用说明

完整证据见 [qa/release-1.11.0.md](qa/release-1.11.0.md)。196 项测试通过；七个平台均完成真实视频下载，TikTok 和抖音直播均完成录制、停止和整片解码。订阅扫描、本地转录、真实 API 翻译和离线翻译 Worker 已验证。用户亲自发送的飞书消息完成收件、分类下载和回执，重启后无重复；隔离 Windows 上 1.10.2 到 1.11.0 的真实安装升级通过，合成配置和文件保留。

平台仍可能要求登录、网络代理或访问权限；测试样本成功不保证所有作品永久可下载。Instagram 本次样本本身无音轨；离线 M2M100 仍会误译，生成中文不代表翻译准确。每周上游检查用于发现更新，后续仍需适配、测试和签名发布。保留工作台数据、账号绑定和模型位置，独立旧版 1.1.8 更新通道保持分离。
