# 跑量影链工坊 1.11.0 候选版

状态：正在验收，尚未发布正式升级通道。平台下载仍有登录和网络阻断，真实直播录制尚未通过；飞书真实收件和安装迁移已通过。

## 更新内容

- yt-dlp 更新到 2026.10.26，FFmpeg 更新到 2026-11-05 的 LGPL shared 构建。新增随包 Deno 2.9.8，为 YouTube 的 JavaScript 挑战提供运行环境。
- 更新 Tauri、React、Transformers.js、Vite、TypeScript、Vitest、Reqwest、Tungstenite 等实际使用的依赖；重新锁定全部传递依赖，修复 Windows 依赖路径上的 TLS/证书相关已知漏洞。
- 适配新版 Reqwest 的表单特性，显式初始化 TLS 加密后端，避免 Reqwest 与飞书 WebSocket 依赖同时启用不同后端时崩溃。
- 修正更新组件的隐式代理探测，让“关闭代理（直连）”与系统/手动模式保持一致，不修改操作系统代理配置。
- 修正 TikTok 直播在辅助网页访问失败时的解析崩溃：已确认房间号后继续查询官方直播接口；保留真实网络错误和未开播状态。
- whisper.cpp 1.9.5/b5454 与现有 M2M100 模型已经是本次核对的上游版本，继续复用。现有模型文件无需重新下载。
- 添加 npm/Cargo 每周依赖检查和官方运行组件更新检查；发现更新先报告、测试，不直接替换用户已安装组件。
