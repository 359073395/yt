# 跑量影链工坊 1.10.2

## TikTok 免费备用解析

- 常规解析失败或只取得音频时，自动尝试 MusicalDown、TikWM、SSSTik；不要求安装助手或购买 API。
- “拿到下载地址”不再直接算成功。媒体为空、不是视频、传输失败或时长明显不符时，尝试尚未使用的来源；每个来源最多尝试一次。
- 修复官方嵌入页 503 / 正文解码失败直接阻断下载的问题。优先复用软件自己保存的 TikTok 登录；不读取其他浏览器的 Cookie。
- 第三方仅接收不带跟踪参数的公开视频链接；平台 Cookie、飞书配置和 AI Key 不会传给第三方。第三方媒体使用独立无平台凭据连接，限制 HTTPS 域名、重定向、响应大小和超时。
- 下载阶段显示当前备用来源和已下载大小。下载文件完成校验后才进入后续处理；标题、封面和已取得的原文字幕信息尽量保留。
- 遇到原平台 HTTP 429 会停止请求，避免连续重试；第三方服务自身失败不会使其他来源永久失效。

## 验证范围与限制

用户反馈的印尼洗发水带货视频 `7613247269298523399` 已经通过原生下载验收：MusicalDown 和 SSSTik 分别成功，视频 54.37 秒、576×1024、H.264 + AAC，并完成全片解码检查。TikWM 在本次网络环境下返回 403，因此仅保留为备用，不宣称其在线测试通过。

免费服务可用性会随网络、限流和网站变化而变化；不承诺每条带货视频都可下载，也不保证免费来源提供原画质。仅下载公开且有权使用的内容。私密、付费或平台限制的内容不保证支持。

普通公开视频对照测试遇到 TikTok HTTP 429，已停止请求，不能将其记为下载通过。限流期间仍需稍后再试；本版本不绕过平台限流。

本次未重新验收直播录制、所有平台实时下载、翻译准确率或多员工多电脑场景，不将本次短视频修复泛化为这些功能已修复。

## 更新方式

现有工作台用户可在软件内点击“更新”。沿用原应用标识、安装模式、更新签名公钥和数据目录；不会重建飞书机器人，也不会重置账号、模型和保存路径。本轮不自动操作用户电脑进行安装。

旧独立版 1.1.8 的更新通道继续分离，不自动迁移到工作台。
