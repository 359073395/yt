# 影链工坊 Desktop 1.1.8

Windows 10/11 本地视频、封面、双语文案、多语言语音识别与中文翻译工具。

采用媒体收件箱式桌面界面：粘贴后先解析为可勾选的作品列表，再统一选择清晰度、输出内容和保存位置。首次启用语音识别或中文翻译时，会明确显示模型大小与保存目录，只有用户确认后才下载。模型窗口可完整显示模型目录，中文翻译可在本地 M2M100 与兼容 OpenAI 格式的 AI 接口之间切换，并能从上游自动获取模型列表。API Key 使用 Windows DPAPI 加密后仅保存在当前电脑。

1.1.8 精简任务输出，仅保留勾选的视频、封面、双语文案，以及平台提供的原版字幕。每行完成状态提供“打开文件夹”，直接打开该条视频目录；队列优先显示真实封面，下载后回填本地封面。同一视频重复下载会使用新目录，不覆盖旧文件。识别或翻译失败仍会明确提示。

## 设计原则

- Tauri 2 + Windows WebView2，不捆绑 Chromium。
- 所有长任务都在 Rust 后台进程或 Web Worker 中运行，界面线程不执行下载、转码或 AI 推理。
- `yt-dlp`、精简 FFmpeg 与 `whisper.cpp` 随正式安装包提供。
- Base / Small / Medium 语音模型按需下载、切换和删除，当前选择会自动记住。
- M2M100 中文翻译模型首次使用时由用户确认后按需缓存，不增加主安装包体积。
- 不想下载本地翻译模型时，可填写兼容 OpenAI Chat Completions 的 URL 与 API Key；程序会从上游读取可用模型，也允许手动填写模型名。
- 作品与模型分别选择存储位置；视频、封面、双语文案与原版字幕保存在同一作品文件夹。
- TikTok 公开作品无需登录；优先读取官方公开播放器，平台临时异常时使用公共解析回退，最后可通过 Windows 自带 Edge 建立一次性匿名播放会话并在任务后清理。
- 更新包由 GitHub Actions 构建并使用 Tauri 签名；应用只安装通过内置公钥校验的新版本。

## 输出文件

```text
作者/日期_标题_[视频ID]/
├── 视频.mp4
├── 封面.jpg
├── 双语文案.txt
└── 原版字幕.srt  # 平台有原文字幕且勾选时保存
```

双语文案是一份“原文 + 中文”对照文件；原文已是中文时不重复翻译。没有平台字幕时，可以通过本地语音识别生成双语文案，但不会把 AI 生成的字幕冒充平台原版字幕。信息 JSON、识别中间文件等仅用于本次临时任务，完成或失败后清理，不修改此前下载目录。

## 本地开发

```powershell
npm install
npm run prepare:runtime
npm test
npm run build
```

`prepare:runtime` 只用于制作安装包，从上游官方发布页取得 Windows 运行组件。终端用户无需运行任何安装助手。
