# 影链工坊 Desktop 1.1.8

- 精简每条视频的输出：视频、封面、双语文案；平台有原文字幕时，可额外保存一份“原版字幕.srt”。不再输出视频信息 JSON、平台介绍、识别中间文件、独立中文文案或中文/双语字幕文件。
- “双语文案”和“原版字幕”可以分别勾选。没有平台字幕时，仍可通过语音识别生成双语文案，不把 AI 生成的字幕冒充原版字幕。
- 每条已完成任务旁增加“打开文件夹”，直接打开这一条视频的本地目录；未全部完成的任务也能查看已保存的文件。
- 队列显示真实封面。TikTok 预览不再依赖可播放地址，封面由后台读取后显示，下载结束再用本地封面回填。
- 重复下载同一视频使用带序号的新目录，不覆盖旧文件；临时任务资料单独存放，结束后清理。
